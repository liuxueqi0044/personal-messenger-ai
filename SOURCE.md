# Source provenance

This repository preserves a sanitized, real development history plus a cumulative public snapshot. The final publication commit collects work that already existed in the development worktree; it should not be read as a single-session implementation.

The original commit order, authorship roles, dates and messages are retained. Commit IDs changed because generated build artifacts, machine-specific paths and a personal email address were removed before publication.

Included:

- application source and automated tests;
- synthetic fixtures and non-secret compatibility profiles;
- reproducible scripts and architecture documentation;
- threat, privacy and acceptance models.

Excluded:

- runtime databases and state;
- virtual-machine images and deployment artifacts;
- screenshots, chat content and account identifiers;
- credentials, API keys, cookies and local secret-store material;
- generated binaries, caches and local build output;
- internal session handoff notes containing machine-specific paths.

The development worktree remains separate from this public snapshot and was not rewritten.
